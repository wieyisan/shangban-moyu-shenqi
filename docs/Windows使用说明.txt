上班摸鱼神器 Windows 使用说明

适用版本：1.3.0｜Windows 10 / 11，64 位（x64）

1. 首次使用

1. 将 OfficeEscape-1.3.0-Windows-x64.zip 完整解压到一个文件夹。
2. 打开解压后的文件夹，双击 OfficeEscape.exe。不要在压缩包里直接运行，也不要只复制 exe 文件。
3. 软件无需安装 Node.js 或其他开发工具。
4. 看网页：在起始页输入网址，点击「前往」，也可点击常用站点。
5. 看本地书籍：点击「导入书籍」或「导入一本书」，选择 TXT、EPUB、PDF。

第一次想熟悉操作，可以点击「体验阅读」打开示例读物。

软件右上角可切换「中文 / English」，语言选择会自动保存；切换只影响软件界面，不翻译书籍或网页。

2. 让正文贴合 Word

1. 先打开一本 TXT 或 EPUB 书籍。
2. 点击右上角「阅读设置」。
3. 点击「Word 贴合：只留正文」。
4. 窗口会缩为约 460 × 300，背景透明、文字深灰、字号 16，并保持置顶；标题栏、地址栏、边框和进度条收起。
5. 用下面的鼠标拖动方法，把正文放到 Word 中合适的位置。

这是覆盖在 Word 上方的透明窗口，不会将文字写入 Word，也不会修改你的文档。PDF 自身的白色页面不能像 TXT / EPUB 一样去除；复杂网页的透明效果取决于网站。

3. 透明模式：全部可以用鼠标操作

将鼠标移到窗口上沿附近（约 28px 高的区域），会自动出现一条小浮栏。

- 移动窗口：按住浮栏左侧「⠿ 拖动」，保持鼠标左键按下并移动，松开后停止。
- 修改配置：点击浮栏「设置」。设置面板打开后可修改字号、颜色、透明度、置顶等；完成后点击面板右上角「×」。
- 找回完整界面：点击浮栏「展开」，显示完整工具栏。
- 隐藏整个窗口：点击浮栏「隐藏」。之后可从系统托盘恢复，或按 Alt+Z。
- 只收起浮栏：点击浮栏「×」，或把鼠标移回正文，约 0.4 秒后自动收起。

浮栏收起后，不会留下常驻把手、背景或边框。正常阅读、滚动正文不需要快捷键。

补充入口：透明模式下右键正文，可选择「阅读设置」「显示 / 收起阅读工具栏」等操作。网页 / PDF 也支持顶部浮栏；浮栏显示时，网页视图会临时为按钮让出空间。

4. 调整阅读效果

在「阅读设置」中：

- 透明模式：去除背景；收起操作界面后，只显示阅读内容。
- 窗口不透明度：100% 最清晰，数值越低，文字与窗口越淡。它与「背景透明」是两项不同设置。
- 字号 / 网页缩放：调整本地正文大小或网页缩放比例。
- 阅读文字颜色：选适合下方文档背景的颜色。Word 白纸背景通常可用深灰色。
- 始终置顶：开启后，在操作 Word 等窗口时，上班摸鱼神器仍显示在前面。
- 自动滚动：0 为关闭，调高后加快滚动。PDF 和部分网页不支持该项。
- 隐藏网页图片：隐藏网页中的图片、视频等内容；部分特殊网页可能不生效。

普通界面点击「小窗」可切换为约 460 × 600 的窗口，再点该位置的「展开」恢复尺寸。它与浮栏的「展开」不同：浮栏的「展开」用于显示完整操作界面。

5. 鼠标移出隐藏

在「阅读设置」打开「鼠标移出隐藏」：

1. 鼠标离开整个窗口边界时，窗口自动隐藏。
2. 鼠标移回原窗口所在区域，窗口自动恢复。
3. 移回后再靠近上沿，就可以唤出浮栏并拖动或修改设置。

“移回正文收起浮栏”和“移出整个窗口隐藏”是不同操作。自动收起浮栏不会隐藏正文。

移出隐藏开关在下次启动时默认关闭，避免找不到窗口。隐藏时会尝试暂停正在播放的网页音视频，恢复时尝试继续播放。

6. 隐藏、恢复与退出

Windows 系统托盘位于任务栏右下角；如果没有看到上班摸鱼神器图标，先点击向上的小箭头，展开隐藏图标。

- 点击上班摸鱼神器托盘图标：恢复窗口。
- 右键托盘图标 →「阅读工具栏（Alt+R）」：找回操作界面。
- 右键托盘图标 →「恢复不透明窗口」：取消透明和移出隐藏，恢复清晰可见的窗口。
- 右键托盘图标 →「退出」：完全退出程序。

注意两个「×」的区别：普通窗口右上角的「×」会把窗口隐藏到托盘；小浮栏里的「×」只收起浮栏，不退出程序。

以下快捷键仅作为备用，鼠标也能完成主要操作：

- Alt+Z：隐藏 / 恢复窗口。
- Alt+R：显示 / 收起阅读工具栏。
- Alt+X：完全退出。
- Esc：在本地阅读界面获得焦点、且处于透明阅读时，显示 / 收起工具栏。

Alt+Z、Alt+X 可以在阅读设置底部修改，点击「保存快捷键」生效。快捷键冲突会显示提示；Alt+R 保留给工具栏，不能设为老板键。

7. 书籍与阅读记录

- TXT：支持常见中文编码，识别章节标题，可通过目录跳转。
- EPUB：按章节顺序提取文字，不保留复杂排版和插图，不支持 DRM 加密。
- PDF：使用内置 PDF 阅读器，缩放、翻页以 PDF 自带工具栏为准。
- TXT / EPUB 会自动保存章节和滚动位置；PDF 暂无应用层阅读进度保存。
- 单文件导入上限 50 MB；不支持 MOBI / AZW3。
- 删除书架条目只删除上班摸鱼神器保存的副本，保留原始文件。

书籍、设置、收藏默认存放于 %APPDATA%\qingyu-reader\library。可在资源管理器地址栏粘贴该路径打开。网页登录会话存放在同一应用数据目录内。

8. 常见问题

找不到窗口或文字太淡：展开任务栏托盘，右键上班摸鱼神器图标，选择「恢复不透明窗口」。

鼠标移到上面没有出现浮栏：确认已经打开阅读内容并收起完整工具栏；移到的是上班摸鱼神器窗口的上沿，不是 Word 窗口的上沿。仍找不到时，可右键正文或通过托盘唤回工具栏。

拖不动：先将鼠标移到上沿，让小浮栏出现，再按住「⠿ 拖动」。直接拖正文主要用于选择文字。

透明模式仍看到一条操作栏：把鼠标移回正文稍等，或点击浮栏「×」。设置面板打开时，可先点击面板右上角「×」。

部分网页登录、视频或透明效果异常：站点可能不兼容内嵌浏览器，尤其是独立登录弹窗、DRM 视频和画布内容；可尝试关闭透明模式或在常规浏览器访问。

启动提示缺少文件：重新完整解压压缩包，保留所有子文件夹，不要只拿出 OfficeEscape.exe。

系统提示发布者未验证：当前测试版未进行商业代码签名，请确认文件来源可信；企业电脑受管理时，按公司的软件使用规定处理。

当前验证范围：Mac 上已验证核心交互与透明绘制，Windows 包已完成文件完整性检查，尚未在 Windows 真机完整验收。
